# Telegram TikTok/Reels/YouTube downloader

## System

Works as a Telegram guest bot: user mentions `@<bot_name> <link>` in a message and the bot replies with the video.

## Tech

- `aiogram` for tg bot
- `yt-dl` for video download
- `cachetools` and `diskcache` for performance tuning
